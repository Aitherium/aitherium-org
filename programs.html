Programs

Four programs, one purpose

Everything the foundation does maps to one of these programs. Each one is judged by what it publishes, not by what it promises.

Program 01

Open Source Stewardship

The foundation maintains the open core of the platform: an AI-native operating system for agents — AitherOS — and the ecosystem of tools around it. Everything is developed in public, runnable on your own hardware, and free to use personally — the core is source-available and the ecosystem around it is permissively licensed (MIT and Apache).

AitherOS

An open AI-native operating system and agent platform: services, orchestration, memory, identity, and the tools that tie agents to the world. Self-hostable first.

View source →

awdk — the agent developer kit

Build agent fleets in three lines, on any backend, local or cloud. The foundation's own agents run on the same kit it publishes.

View on GitHub →

The aw* ecosystem

A family of small, composable building blocks — skills, tools, memory, search, and more — registered and documented as an ecosystem a stranger can explore and adopt.

Explore the family →
Program 02

Open Models

The foundation trains and releases models with published weights — from small brains that run entirely on a laptop or phone, to frontier-scale coder weights. The weights are the point: anyone can audit, fine-tune, serve, and keep them.

Bonsai

A family of open-weights models designed to run on-device — including conversational brains that work with no connection at all.

Served via awdk →

Coder and reasoning weights

Larger open models for coding and reasoning, published with the same openness as the rest of the stack — served through the same self-hostable lanes.

Browse releases →

Publish, don't hoard

An open model nobody can run is a press release. Every model the foundation ships is loadable through open tooling on ordinary hardware, and the serving stack is open too.

Program 03

Education & the Operator Doctrine

The foundation's thesis is that the coming wave turns people into operators — directors of their own agents — rather than casualties of automation. That only becomes true if the knowledge to operate is actually taught. This program publishes the teaching.

The five-step tour

The platform, explained in five steps — no account, nothing to install. The architecture and service manuals live in the source with the code.

Talks & the blog

Field reports from running an open AI fleet, plus talks and essays on the operator doctrine — what it means to direct agents for a living.

The doctrine itself

Program 04 — the engine

Community Infrastructure

This is the program the other three exist to feed. Openness is worthless without a commons to share it in — and a commons is not a server, it is the people who use it. The foundation runs the spaces and the lanes; the community runs the network.

The rooms

Public chat on the open relay — where the builders and the operators actually talk, ask, and ship. The knowledge of the whole ecosystem moves through these rooms daily.

Join the rooms →

The nodes

Any machine can join the fleet as a node — a laptop, a workstation, a dedicated box. The more distributed the hardware, the harder it is for anyone to control the network.

Run a node →

Spaces & forums

Persistent spaces and forums for longer conversations, project homes, and community knowledge that outlives a chat window.

Explore spaces →

The builders

50+ public repositories and a contribution lane that starts with a newcomer-friendly issue. The ecosystem only grows when people contribute to it — and they do, daily.

The teachers

The operator doctrine, the docs, the talks — every operator the community trains is one more person who can never be locked out of their own infrastructure.
