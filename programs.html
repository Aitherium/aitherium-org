Programs

Four programs, one purpose

Everything the foundation does maps to one of these programs. Each one is judged by what it publishes, not by what it promises.

Program 01

Open Source Stewardship

The foundation maintains the open-source core of the platform: an AI-native operating system for agents — AitherOS — and the ecosystem of tools around it. Everything is developed in public, licenced permissively, and runnable on your own hardware.

AitherOS

An open AI-native operating system and agent platform: services, orchestration, memory, identity, and the tools that tie agents to the world. Self-hostable first.

View source →

awdk — the agent developer kit

Build agent fleets in three lines, on any backend, local or cloud. The foundation's own agents run on the same kit it publishes.

View on GitHub →

The aw* ecosystem

A family of small, composable building blocks — skills, tools, memory, search, and more — registered and documented as an ecosystem a stranger can explore and adopt.

Explore the family →
Program 02

Open Models

The foundation trains and releases models with published weights — from small brains that run entirely on a laptop or phone, to frontier-scale coder weights. The weights are the point: anyone can audit, fine-tune, serve, and keep them.

Bonsai

A family of open-weights models designed to run on-device — including conversational brains that work with no connection at all.

Served via awdk →

Coder and reasoning weights

Larger open models for coding and reasoning, published with the same openness as the rest of the stack — served through the same self-hostable lanes.

Browse releases →

Publish, don't hoard

An open model nobody can run is a press release. Every model the foundation ships is loadable through open tooling on ordinary hardware, and the serving stack is open too.

Program 03

Education & the Operator Doctrine

The foundation's thesis is that the coming wave turns people into operators — directors of their own agents — rather than casualties of automation. That only becomes true if the knowledge to operate is actually taught. This program publishes the teaching.

Docs & quick starts

Public documentation covering the platform, its architecture, and its services — written for a person arriving with no prior context.

Read the docs →

Talks & the blog

Field reports from running an open AI fleet, plus talks and essays on the operator doctrine — what it means to direct agents for a living.

Read the blog →

The doctrine itself

A distilled operating doctrine — accumulated from years of real sessions — published as a public pack anyone can install and learn from, on any machine.

Find the packs →
Program 04

Community Infrastructure
