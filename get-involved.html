There is a place for you in the open layer

The community is the infrastructure — the code, the nodes, and the knowledge only exist because people show up. Four ways in, in the order that matters most.

01 · The engine

Join the community first

The fastest way to be useful is to show up where the work is visible. The rooms are public, persistent, and full of the people who actually run this stuff — the knowledge of the whole ecosystem moves through them daily. Everything else on this page is a continuation of this step.

The community's home: help, show-and-tell, and the people building with Aitherium. One click joins — no account needed beyond Discord itself.

02 · Hardware

Run a node — become the infrastructure

The network's strength is that it is not hosted by one company — it is hosted by its users. Every machine a member runs is infrastructure the community owns: the more distributed the hardware, the harder it is for anyone to control the network. Open infrastructure only stays open if it is distributed.

Self-host your own instance

Run the full platform on your own hardware — a laptop, a workstation, a box in a closet. Every capability is built to run this way. Docs and the quick start are public.

Read the quick start →

Try it, then join the network

You can explore the platform right now as a guest — no account, nothing to install. The open network is in early access: join the waitlist and bring your machine when the door opens.

Try it now →
