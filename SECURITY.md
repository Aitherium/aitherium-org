# Security policy

Report a vulnerability in this site privately, never in a public issue:

- GitHub private vulnerability reporting:
  https://github.com/Aitherium/aitherium-org/security/advisories/new
- or email **security@aitherium.com**.

Include what you found, where, and how to reproduce it. We acknowledge reports within
3 business days and tell you what we will do and when. The site has no server-side
code and collects no personal data; the latest `main` is the only supported version.
